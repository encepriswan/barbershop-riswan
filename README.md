## 📌 DESKRIPSI SISTEM

Barbershop Riswan merupakan aplikasi management barbershop berbasis web yang dikembangkan menggunakan framework Laravel.

Sistem ini dibuat untuk membantu proses pengelolaan barbershop secara digital mulai dari:

- Booking layanan
- Pengelolaan antrian
- Pembayaran
- Transaksi
- Dashboard admin
- Monitoring customer

Sistem dirancang modern, responsif, interaktif, dan mempermudah pengelolaan operasional barber secara real-time.

# 🪑 SISTEM ANTRIAN

Sistem antrian dibuat seperti konsep bioskop/barber modern:

## 🔥 Kursi Barber
- Maksimal 4 kursi barber
- Kursi tidak bergeser
- Jika selesai → kursi menjadi kosong

## 🕒 Kursi Tunggu
- Maksimal 10 kursi waiting
- Bergeser otomatis sesuai urutan check-in

---

# 💳 SISTEM PEMBAYARAN

- Total harga otomatis
- Multi layanan = 1 transaksi
- Status pembayaran:
  - unpaid
  - paid
